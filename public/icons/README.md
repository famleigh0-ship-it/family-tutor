# Icons

`icon-192.png` and `icon-512.png` are generated by `scripts/generate-icons.js`
— a solid `#1e40af` background with a centered white circular mark, kept
inside the maskable-icon safe zone (~40% radius). Pure Node (`zlib` only, no
`canvas` dependency — see that script's header for why). Regenerate with:

```bash
npm run generate-icons
```

To use real artwork instead, just replace both files with square PNGs
(192x192 and 512x512, maskable-safe padding) and skip the script.
